## The fine print nobody puts in the deal headline

This is the section deal aggregators tend to gloss over, and it should shape your decision.

**Refunds: none by default.** RackNerd's terms state: "Refunds are issued on a case-by-case basis since by default no refunds are provided once payment is received." There's no money-back guarantee and no trial period, and prepaid account credit isn't refundable either. Unlike Hostinger's 30-day guarantee, a RackNerd purchase is effectively final. If you're unsure about latency or performance from your region, order the cheapest annual plan rather than a big one, or start with a monthly plan from the standard line.

**Unmanaged, from minute one.** Free support covers hardware, power, network connectivity, and service availability — best effort, 24/7. The terms explicitly exclude software, operating system issues, firewall configuration, server hardening, malware cleanup, and script troubleshooting. If you want someone to fix your WordPress plugin conflict, this isn't the host for that expectation.

**No built-in backups, snapshots, API, or hourly billing.** The plan pages don't offer automated backups — you run your own (restic, rsync, or a cron job to object storage). There's no API for programmatic server management. Servers are billed monthly or annually, not by the hour.

**Cancellation requires notice.** Contracted services need written cancellation through the client area at least 7 days before the renewal date, or you're billed another term. Downgrades need 5 days' notice. Deleting data happens on cancellation.

**No coupon codes for VPS.** VPS specials don't require a promo code — the deal price is the listed price. Codes circulating on coupon sites claiming 30% or 70% off VPS plans are stale or lead-generation bait. RackNerd's currently advertised codes apply to dedicated servers only.
